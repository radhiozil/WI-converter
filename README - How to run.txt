WI Builder (offline)

1. Unzip this whole folder (do not run it from inside the zip).
2. Double-click "WI Builder.exe".
3. Upload the OJTI and MOI (.docx), review, then choose "Download WI (.docx)" and pick where to save.

The app has no internet access and does not send your files anywhere.
It is not code-signed, so Windows SmartScreen may warn: choose "More info", then "Run anyway",
or ask IT to approve it.
